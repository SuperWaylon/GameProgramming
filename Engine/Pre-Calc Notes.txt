* Functions have 1 output(f(x) or y) per input(x). Tested by vertical line test.
* Vertical line test: If crossed 2+ times, operation is not a function.
* Notation f(x) and otherwise.
* "If given x, return y" (Same as coding pretty much)
* Evaluate: 1) Substitute 2) Solve
* Domain: Independent Values (x) Every possible input
* Range: Dependent Values (y) Every possible output
* f(x) = # (Domain = All real numbers, Range = #)
* 
* Library of Functions
* Constant Function (f(x) = #) (Domain = All, Range = #)
* Linear Function (g(x) = x) (Domain \& Range = All)
* Quadratic Function / Parabola (h(x) = x^2) (Domain = All, Range >= 0)
* Cubic Function (f(x) = x^3)
* Square Root Function (g(x) = sqrt(x)) (Domain >= 0 , Range >= 0)
* Cube Root Function (h(x) = x^(1/3)) (Domain = All, Range = All)
* Rational Functions (k(x) = 1/x) (Domain = (x != 0) ,  Range = (x != 0))
* Absolute Value Function (f(x) = |x|) (Domain = All, Range >= 0)
* Exponential Function (b(x) = 2^x) (Domain = All, Range >= 0)
* Logarithmic Function (l(x) = log(x)) (Domain > 0, Range >= 0)

* Horizontal asymptote (End Behavior): Degrees show scenarios (y = ?)
* Bottom Degree > Top = HA: y=0
* Top == Bottom = HA: (top coeff)/(bottom coeff) because the highest coeff does the heavy lifting in the function
* Bottom < Top =  No HA 

* ex. y = (-4x^2)/(x^2+2x-0) -> 4/1 = 4 so HA = -4. y intercept = 0, x intercepts = 0, VA = (x=-4 & x = +2)
* ex2. y = (x^2(x-1))/((x+2)(x-4)) -> 1/1 so HA = 1, y intercept = -1, x intercepts = 1

Synthetic Division

Crossing -> Odd Multiplicity
Bounce -> Even Multiplicity

Max Turning Points = degree-1

Bounds

* Bottom row all alternates - and + = Lower Bound

Find Imaginary/Irrational Roots with Quadratic Formula

* Exponential functions: y=#^x
* Dependent Variable = y
* Independent Variable = x
* Base = #
* Have Horizontal Asymptotes
* y intercept = 1 (#^0 = 1)

* (0,1) Will always be a point on the parent function
* HA: y = 0
* If base > 1, increase left to right
* If base < 1, decrease left to right
* If base = 1, y = 1

* Logs ask (base) of what power gives me y?
* Logs undo exponents, switch the inputs and outputs for the x and y of exponents.
* Point on graph is (1,0)
* VA: x=0
* Base will be positive for this class
* To input log bases in desmos, simply put log_(base).

* Solving exponential functions: Get the bases to match. If the bases are the same, find the value of x that makes the exponent match.
* 3^(x-4)=1 = 3^(0) so x = 4 (4-4 = 0)
* 8^x = 64 ; 8^x = 8^2 ; x = 2
* (2^3)^x = 2^6 -> 2^3x = 2^6
* (1/9)^x = 243 -> (3^-2)^x = 3^5 -> 3^-2x = 3^5 -> -2x = 5 -> x = -2.5
* 2^3x+1 = 8 -> 2^3x+1 = 2^3 -> 3x+1 = 3 -> 3x = 2 -> x = (2/3)
* 4 * 2^4 = 32^2x -> 2^6 = (2^5)^2x -> 6 = 10x
